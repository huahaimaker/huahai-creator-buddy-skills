# 花海猫角色 DNA

## 身份定位

“花海猫”是一个好奇、会动手、愿意探索和验证的内容伙伴。它不是被摆放在画面里的吉祥物，而是负责把抽象知识变成行动的参与者。

角色参考图：`../assets/huahai-cat-character-sheet.png`。

## 不可丢失的识别锚点

按重要性从高到低：

1. 奶白色、略蓬松的拟人猫，超大直立尖耳，耳内浅粉。
2. 头大身小，深蓝色圆眼带高光，小粉鼻，圆润友好的脸。
3. 深森林绿棒球夹克，米白袖子与罗纹边；左胸有浅色字母 `C`。
4. 卡其色宽松工装裤，两侧有口袋。
5. 绿白运动鞋。
6. 黑色斜挎小包，背带斜跨上身。
7. 奶白色卷曲长尾。

正面或四分之三视角尽量保留至少 5 个锚点。动作或遮挡较大时至少保留“尖耳蓝眼、绿色夹克、卡其裤、斜挎包、卷尾”中的 3 个，并避免改变服装色系。

## 比例与气质

- 约 3.5–4.5 头身，头和耳朵明显偏大。
- 手脚短而灵活，轮廓圆润，但不能变成人类儿童戴猫头套。
- 可爱、聪明、好奇、积极；专注工作时可以严肃或困惑，不必每张都张嘴微笑。
- 亲和但不幼儿化，不使用婴儿奶嘴、夸张腮红、闪粉眼睛或表情包动作。

## 正文配图中的简化规则

允许简化毛发纹理、衣服褶皱和鞋带，但不能简化掉角色身份。优先保留剪影、配色和服装锚点；不要为了画面极简把它退化成一只普通白猫。

角色通常占画布约 15%–35%。需要强调情绪或状态时可以更大，但避免变成角色立绘或封面海报。

## 核心职责与动作库

花海猫适合承担：

- 探索：拿放大镜、观察信号、沿线索前进、打开未知的门。
- 整理：分类卡片、收纳素材、把混乱线团梳理成路径。
- 搭建：搭桥、铺路、组装低科技机器、修补断口。
- 验证：称重、测量、打勾、用小实验比较前后差异。
- 连接：接线、递交、把两个孤岛接起来、把内容送到读者手中。
- 记录：从斜挎包取出笔记、贴标签、收集证据、复盘足迹。

动作必须服务核心观点。不要只让角色挥手、站立、摆拍或指向一张已经完整的图表。

## 参考图使用边界

参考图只回答“角色是谁”。生成时必须忽略并禁止复制：

- 橙黄色纹理背景。
- 正面、侧面、背面并排的三视图版式。
- `FRONT / SIDE / BACK / 正面 / 侧面 / 背面` 等文字。
- 原图的静态站姿、比例尺和角色设定稿呈现方式。

不要把三视图图片直接贴进成品，也不要生成三个并排角色，除非用户明确要求新的角色设定图。

## 禁止漂移

- 不要变成狐狸、狗、兔子或普通四足猫。
- 不要改成黑猫、橘猫或纯灰猫。
- 不要把眼睛改成绿色、红色或黑色豆豆眼。
- 不要换成西装、连帽衫、宇航服等新服装，除非用户明确要求换装。
- 不要漏掉尾巴、重复尾巴、增加耳朵或产生多余肢体。
- 不要把 `C` 变成醒目的大标题；它只是夹克上的身份细节。
